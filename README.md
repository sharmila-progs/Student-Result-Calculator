# Student Result Calculator

This is my first Python project.

## About Project
This project calculates student total marks, average, percentage, and result based on marks obtained in three subjects.

## Programming Language
- Python

## Features
- Student name input
- Subject marks input
- Total marks calculation
- Average calculation
- Percentage calculation
- Pass or Fail result

## Sample Output

```text
Student Name: Ravi
Total Marks: 240
Average: 80
Percentage: 80%
Result: Pass
```
